## 🏆 Architecture Highlight

> A pattern from production that I'm proud of:

```
Incoming Request
       │
       ▼
┌─────────────────────────────────┐
│  Layer 1 — In-Memory LRU        │  ← 1–5ms   · 5,000 entries · 24h TTL
│  Normalized keys · Zero I/O     │    ~95% of traffic served here
└────────────┬────────────────────┘
             │ miss
             ▼
┌─────────────────────────────────┐
│  Layer 2 — Redis                │  ← 10–50ms · Shared · Atomic · Durable
│  Survives restarts · All nodes  │
└────────────┬────────────────────┘
             │ miss
             ▼
┌─────────────────────────────────┐
│  Layer 3 — AI Service (BullMQ)  │  ← 200–800ms · Rate-limited · Queued
│  Result → write-back → promote  │    Same miss never happens twice
└─────────────────────────────────┘
```
